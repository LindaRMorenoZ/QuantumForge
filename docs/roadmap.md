# Development roadmap

This roadmap describes intended work, not implemented functionality.

1. Establish physical and numerical conventions.
2. Add wavefunction representation and validation.
3. Add probability density and probability current.
4. Add the Bohmian velocity field with explicit assumptions and singularity handling.
5. Add trajectory integration with convergence tests.
6. Add free-particle Gaussian wave-packet experiments.
7. Add coherent superpositions and interference experiments.
8. Add a double-slit model after the preceding components are validated.
9. Consider higher-dimensional and many-particle extensions only after the foundations are stable.
